# lulu-star — Catch the Stars

Hand-controlled roguelike catching game (pygame + MediaPipe).

## Run

```bat
run_game.bat
```

Or:

```bat
python catch_the_stars.py
```

## Install

```bat
pip install -r requirements.txt
```

Needs a webcam for hand control (mouse / keyboard still work).

## Controls

| Input | Action |
|-------|--------|
| Hand / mouse / A D / arrows | Move paddle |
| 1 2 3 / click / thumbs-up | Choose cards |
| Shop: swipe down + thumbs-up | Refresh (left) or Continue (right) |
| Shop: R | Pay to refresh offers |
| Shop: Space | Skip / continue (no buy) |
| Q E F G T | Use items |
| Both fists | Restart to difficulty menu |
| H | Toggle hand |
| ESC | Quit |

## Features

- Easy / Normal / Hard
- Wave upgrades, Boss waves, Frenzy waves, Shop
- Shop: skip free, refresh for score, random items & mild buffs
- Procedural BGM / SFX
